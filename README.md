# 202366050-lamaalothman-assignment1

This project is a personal portfolio website created for Assignment 1 of the Web Engineering course at KFUPM (SWE 363). It introduces me as a Software Engineering student and presents information about me, selected projects, and ways to contact me.

## Features

- Home section with GitHub and LinkedIn links
- About Me section with a short introduction
- Projects section featuring RouteRepair and KFUPM StudyVerse
- Contact form with a confirmation message
- Dark and light theme toggle
- Responsive design for desktop, tablet, and mobile
- Smooth scrolling between sections

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid and Flexbox
- Local Storage

## Running the Project Locally

1. Clone the repository:

```bash
git clone https://github.com/5cvi9/202366050-lamaalothman-assignment1.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.

No additional installation or dependencies are required.
