# AI Usage Report

## Tools Used & Use Cases

I used ChatGPT as an AI-assisted tool while developing my personal portfolio. I used it to review parts of my HTML, CSS, and JavaScript, explain concepts that I wanted to understand better, and suggest improvements to the organization and design of the website.

ChatGPT was also used to help with responsive design, code comments, Git commit organization, and project documentation. I used the suggestions as guidance while developing and reviewing the final version of the portfolio.

## Benefits & Challenges

Using ChatGPT helped me understand some web development concepts more clearly and made it easier to review my work. It was especially useful when working with responsive design, CSS Grid and Flexbox, JavaScript interactions, and organizing the project into clear development steps.

One challenge was that not every AI suggestion was necessary or suitable for my portfolio. I needed to review the suggestions, decide which ones were useful, and test the code to make sure it worked correctly with the rest of my project.

For example, AI suggested adding an active navigation feature that highlights the current section while scrolling. After reviewing the assignment requirements, I decided not to include it because the portfolio already met the interactivity requirement without it.

## Learning Outcomes

Through this process, I improved my understanding of HTML page structure, CSS styling, responsive layouts, and JavaScript event handling. I also learned how media queries can adapt a website for tablet and mobile screens and how localStorage can be used to remember a user's theme preference.

I also gained more experience with Git and learned how meaningful commits can be used to organize and document the development process.

## Responsible Use & Modifications

I did not use AI suggestions without reviewing them first. I checked the suggested code, made changes when necessary, and tested the features before including them in the final project.

I also modified suggestions to match my own portfolio design and assignment requirements. For example, Figma was initially considered under technologies for the StudyVerse project, but I changed it to "Design Tool" because this description was more accurate.

Some optional AI suggestions were not included because they were not necessary for the final website. This allowed me to use AI as a supporting tool while still understanding the code and making the final decisions about my project.
